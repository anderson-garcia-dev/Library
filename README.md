## Proyecto Libreria

Este proyecto esta realizado con Laravel 13 y PHP 8.5. Consiste en una creacion de libreria para amar un stock. Donde el Administrador tiene la potestad de crear, listar, actualizar, borrar y filtrar libros por categorias. Tambien permite hacer un CRUD de categorias.

## Laravel

Laravel 13

## PHP

PHP 8.5

## Comandos a correr para ejecutar el proyecto Local

1- `composer install`
2- `npm install && npm run build`
3- `php artisan migrate` (Corre todas las migraciones del proyecto [books, categories])
4- Registrarse para poder usar el proyecto. Este cuenta con Laravel UI --Auth que muestra un dashboard que continen el workflow del proyecto

## Base de datos

1- Postgres 18.6

## Tablas (Migraciones propias)

1- Books
2- Categories
